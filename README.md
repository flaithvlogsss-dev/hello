# Слизевик

Интерактивное генеративное искусство. Десятки тысяч частиц ползают по чашке Петри и сами выращивают сети, как настоящий слизевик *Physarum polycephalum*.

Частицы работают по агентной модели Джеффа Джонса (2010). У каждой частицы впереди три датчика. Она чувствует след, оставленный другими, и сворачивает туда, где он сильнее. След понемногу расплывается и испаряется.

## Как открыть

Откройте `index.html` в браузере. Сборка и зависимости не нужны.

## Что можно делать

- Класть в чашку **овсянку** (слизевик к ней тянется) и **соль** (слизевик её обходит): кликните по чашке или проведите по ней.
- Переключать характер узора: Сеть, Пена, Жилки, Буря.
- Крутить параметры модели: угол датчиков, поворот, дальность датчиков, шаг, испарение следа, скорость.
- Менять краски и засевать чашку заново.
- **Пробел** ставит на паузу.

## Опубликовать на GitHub Pages

Settings → Pages → Deploy from a branch → выберите ветку и папку `/ (root)`.
