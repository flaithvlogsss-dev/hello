# Слизевик

Абстрактная живая картина. До миллиона светящихся частиц трёх видов ползают по экрану, оставляют след и сворачивают туда, где след сильнее. Из этого сами собой вырастают узоры, как у слизевика *Physarum polycephalum*. Частицы тянутся к своему виду и избегают чужих, а курсор закручивает их в вихри.

Работает на видеокарте через WebGL2 (агентная модель Джеффа Джонса, 2010).

## Как открыть

Откройте `index.html` в браузере. Сборка и зависимости не нужны, нужен браузер с WebGL2 (любой свежий Chrome, Safari, Firefox).

## Управление

| Действие | Что происходит |
| --- | --- |
| Вести курсором | Частицы закручиваются вокруг курсора и тянутся за ним |
| Зажать | Всё засасывает в воронку |
| Отпустить | Взрыв и ударная волна |
| Круги по часовой или против | Меняют направление вихря |
| Колесо мыши | Радиус влияния курсора |
| `M` | Мутация: частицы плавно меняют поведение |
| `R` | Засеять заново (россыпь, кольца, вспышка) |
| `1`–`5` | Палитры: Сияние, Лава, Глубина, Жемчуг, Тушь |
| Пробел | Пауза |
| `H` | Скрыть панель |

Если курсор ушёл с экрана, картину сам водит невидимый «призрак».
