# Люмина

Живая картина из светящихся частиц. До миллиона частиц трёх видов ползают по экрану, оставляют след и сворачивают туда, где он сильнее. Из этого сами собой вырастают неоновые узоры, как у слизевика *Physarum polycephalum*. Частицы тянутся к своему виду и избегают чужих, а курсор закручивает их в вихри, воронки и взрывы.

Работает на видеокарте через WebGL2 (агентная модель Джеффа Джонса, 2010).

## Две версии

| Файл | Для чего |
| --- | --- |
| `index.html` | Обычная веб-версия. Открывается в браузере, все материалы открыты сразу. |
| `yandex/index.html`, `dist/lumina-yandex.zip` | Сборка для Яндекс Игр: SDK, реклама, облачные сохранения, шрифты внутри архива. |

Сборка для Яндекса генерируется из `index.html`. После правок в `index.html` пересоберите её:

```bash
python3 tools/build_yandex.py
```

## Управление

| Действие | Что происходит |
| --- | --- |
| Вести курсором | Частицы закручиваются вокруг курсора и тянутся за ним |
| Зажать | Всё засасывает в воронку |
| Отпустить | Взрыв и ударная волна |
| Несколько взрывов подряд | Комбо: каждый следующий мощнее (×2, ×3…) |
| Правая кнопка | Отталкивает частицы |
| Двойной клик или двойное касание | Сверхновая: белая вспышка и мощная волна |
| Потрясти мышь | Узор рассыпается в хаос и собирается заново |
| Круги по часовой или против | Меняют направление вихря |
| Колесо мыши | Радиус влияния курсора |
| Несколько пальцев | На телефоне каждый палец работает как отдельный вихрь |
| `1`–`7` | Материалы: Сияние, Лава, Глубина, Жемчуг, Тушь, Хром, Перламутр |
| `O` | Открытия (достижения) |
| `K` | Симметрия: курсор отражается в 2, 4 или 6 копиях |
| `T` | Замедление времени |
| `S` | Звук: гул, ветер от движения и взрывы |
| `M` | Мутация: частицы плавно меняют поведение |
| `R` | Засеять заново (россыпь, кольца, вспышка) |
| Пробел | Пауза |
| `H` | Скрыть панель |

В материалах «Хром» и «Перламутр» свет идёт от курсора: поверхность отблёскивает там, где вы водите.

Если курсор ушёл с экрана, картину сам водит невидимый «призрак».

## Открытия

Десять скрытых достижений: Вихрь, Воронка, Большой взрыв, Цепная реакция, Сверхновая, Хаос, Мандала, Стоп-кадр, Мутант, Созерцание. Каждое открытие показывает уведомление, прогресс сохраняется.

## Яндекс Игры

### Что встроено

- SDK (`/sdk.js`), `LoadingAPI.ready()` после загрузки, `GameplayAPI.start/stop` при паузе, открытом меню, рекламе и свёрнутой вкладке.
- События `game_api_pause` и `game_api_resume` ставят игру и звук на паузу.
- Полноэкранная реклама при нажатии «Заново», не чаще раза в 90 секунд. Игра и звук на это время замирают.
- «Хром» открывается после 3 открытий, «Перламутр» после 6. Любой из них можно открыть сразу за рекламу с наградой.
- Сохранения в облаке игрока (`player.setData`) с копией в localStorage.
- Язык берётся из `ysdk.environment.i18n.lang`: русский для ru, be, uk, kk, uz, для остальных английский.
- Все файлы внутри архива, внешних запросов нет. Контекстное меню, выделение текста и масштабирование отключены.
- На слабых устройствах разрешение автоматически снижается, если кадр стабильно дольше 26 мс.

### Как загрузить

1. Откройте [консоль разработчика Яндекс Игр](https://games.yandex.ru/console/) и создайте приложение.
2. Во вкладке с архивом загрузите `dist/lumina-yandex.zip` (внутри `index.html` в корне и папка `fonts`).
3. Заполните карточку: название, описание, иконку, обложку и скриншоты на русском и английском. Подходящие категории: «Антистресс», «Казуальные».
4. Отправьте на модерацию.

Turn on symmetry to draw mandalas, slow down time, and find ten hidden discoveries plus two special materials: liquid chrome and iridescent nacre. No rules and no losing, just light and calm.
